# Source map: spectral, wave, and quantum problems 196–220

Checked on 2026-09-13. This map records the explicit source locations used to select each question. Full references, precise normalizations, and targeted resolution-search topics appear on the problem pages. Searches included the latest available versions and recent proof claims; this is a documented literature review, not a proof that no solution exists.

The batch draws on original papers, a quantum-chaos book chapter, an applied harmonic-analysis book chapter, an encyclopedia chapter, expert surveys, and workshop problem sheets. No numerical linear algebra problems are included.

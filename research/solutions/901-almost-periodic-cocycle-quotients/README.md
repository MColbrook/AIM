# AIM 901: Finite-dimensional detection of reduced almost-periodic Banach cocycles

**Author and submitter:** Matthew J. Colbrook, Department of Applied Mathematics and Theoretical Physics, University of Cambridge, United Kingdom. [mjc249@maths.cam.ac.uk](mailto:mjc249@maths.cam.ac.uk); [department profile](https://www.damtp.cam.ac.uk/person/mjc249).

**Status:** Solved — Affirmative proof.

Every nonzero reduced almost-periodic Banach cocycle class is detected by an unbounded cocycle in a finite-dimensional quotient, for arbitrary topological groups.

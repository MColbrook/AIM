# 1018. Can spectral type vary within a limit-periodic Schrödinger hull?

**Area:** Spectral theory and aperiodic media
**Status:** ✅ SOLVED
**Last checked:** 2026-11-03

## Problem statement

Let $`V:\mathbb Z\to\mathbb R`$ be a bounded uniform limit of periodic sequences. Define $`(SV)(n)=V(n+1)`$ and the uniform hull
```math
\Omega_V=\overline{\{S^kV:k\in\mathbb Z\}}^{\|\cdot\|_\infty}.
```

For $`W\in\Omega_V`$, let
```math
(H_Wu)(n)=u(n-1)+u(n+1)+W(n)u(n)
\quad\text{on }\ell^2(\mathbb Z).
```

Write
```math
\mathcal T(W)=\{t\in\{\mathrm{pp},\mathrm{ac},\mathrm{sc}\}:
\mathcal H_t(H_W)\ne\{0\}\},
```

where the subspaces denote the pure-point, absolutely continuous and singular continuous parts. Must $`\mathcal T(W)`$ be independent of $`W\in\Omega_V`$, for every such $`V`$?

This spells out the basic spectral classification in Damanik–Fillman, Question 10.2, and Damanik–Gan, Remark (v). The assertion concerns every hull element. It does not require equal eigenvalue sets or equivalent maximal spectral measures.

## Application

Hull elements describe different phases of the same aperiodic medium. The question asks whether changing phase can change its spectral classification.

Constancy is required for every hull element, rather than almost surely. A theorem for one dyadic variable-off-diagonal Jacobi hull and generic uniform spectral classes do not settle all constant-off-diagonal models.

The 2026 Jacobi result proves pure singular continuity throughout one dyadic hull.

# 620. A multimarginal Minty converse

**Area:** Continuous optimization and monotone operator theory
**Status:** 🔵 OPEN
**Last checked:** 2026-10-30

## Problem statement

Let $`H`$ be a real Hilbert space, let $`N\geq3`$, and put $`I=\{1,\ldots,N\}`$. Call $`\Gamma\subseteq H^N`$ **$`c`$-monotone** if, for all $`x,y\in\Gamma`$ and every nonempty proper $`K\subset I`$,

```math
\left\langle\sum_{i\in K}(x_i-y_i),\ \sum_{j\notin K}(x_j-y_j)\right\rangle\geq0.
```

Here $`c(x_1,\ldots,x_N)=\sum_{i<j}\langle x_i,x_j\rangle`$. Call $`\Gamma`$ maximally $`c`$-monotone if it is $`c`$-monotone and is contained in no strictly larger $`c`$-monotone subset of $`H^N`$.

Must every maximally $`c`$-monotone $`\Gamma`$ satisfy

```math
\left\{\sum_{i=1}^N x_i:(x_1,\ldots,x_N)\in\Gamma\right\}=H?
```

For two marginals this is Minty's classical theorem. The converse implication, from this range condition to maximal $`c`$-monotonicity, is already proved for every finite number of marginals. No splitting potentials, cyclic monotonicity of higher orders, or regularity assumptions are imposed here. [1]

## Application

This is a structural question in the convex analysis underlying multimarginal optimal transport. It asks whether inclusion maximality gives a full-domain resolvent parametrization, as in classical monotone operator theory. [1]

## Status review

Literature checks on18October2026 found no complete resolution of this exact converse. Lim's counterexample concerns a contact set generated by conjugate potentials which is explicitly **not** maximally $`c`$-monotone; it does not satisfy the premise here.
